# Maroon — Luxury E-Commerce Platform

A high-end, full-stack e-commerce web application engineered to blend modern luxury editorial design with robust software architecture.

## 🚀 Tech Stack

- **Backend:** PHP 8.2+, Laravel 12, Eloquent ORM, SQLite
- **Frontend:** React, TypeScript, Inertia.js, HTML5/CSS3
- **Architecture:** Monolithic SPA integration via Inertia.js

## ✨ Key Features

- **Relational Cart Engine:** Secure, database-backed shopping bag utilizing Eloquent ORM to bundle items under user sessions and calculate totals in real-time.
- **Authentication Guardrails:** Automated login redirects protecting the checkout pipeline for guest users.
- **Editorial Product Showcase:** Dynamic React components handling custom size selection, variable quantities, and layout grid views.
- **Data Validation & Media Ingestion:** Server-side validation rules for inventory items alongside image asset storage management.
